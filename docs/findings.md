# Findings

Moved from the Q & A in Pathwise_notes.Rmd.

- **EPPO API v2:** host classes Major host, Host, Alternate, Wild/Weed, Experimental, Doubtful host, Non-host (no "Minor host"). Lineage: Kingdom Plantae > Class (Pinopsida; Angiospermae) > Category (e.g. Basal monocotyledons, Fabids) > Order > Family > Genus. Unknown codes return HTTP 400. https://eppo.cloud/api/docs is an unrelated company.
- **Lovdata:** 305 citable units. Bark beetles regulated as "Scolytidae spp. (ikke-europeiske arter)" (Vedlegg 2, nr. 10); alias file maps Scolytinae -> Scolytidae, conifers -> Coniferales/bartrær. Not named in the regulation: Xylella, Aromia, Lymantria, Dendroctonus, Polygraphus, Fusarium circinatum. Vedlegg 5A tariff numbers are an older format. Mattilsynet holds genus-level import data (§ 20, § 23a): a data request, not v1.
- **First runs:** ~30 s cold, seconds when cached. Most classes are `large`, as expected for upper-bound CN8 lines; Class B is often much lower (IPSXCA wood: A 1.26 billion kg, B 0.43 million kg).

- **AGRLAX (Agrilus anxius, 2026-10-20):** hosts all Betula, present in CA and US. Before genus filtering, 90 % of "non-conifer wood from pest-present countries" was oak; with it, 47 t/year (mostly pallets) instead of 5.3 million kg. Lovdata: Vedlegg 1 nr. 2.1 (pest), Vedlegg 4A nr. 45, and the origin rule Vedlegg 3 nr. 11 (Betula from Canada and USA).
- **EPPO host commodities / pathways (2026-10-20):** GD lists host commodities per pest (categories: plants for planting, bulbs or tubers, seeds, pollen, cut flowers or branches, fruits or vegetables, stored products, non-squared wood, squared wood, bark, packaging material, manufactured articles, plant waste, soil/growing medium, agricultural machinery, all commodities), at genus level, only for EPPO/EU-listed pests (user guide p. 13-14, `docs/reference/eppo_gd_general_user-guide.pdf`). Not in API v2 (only a count, `infos$pathwayhost`) nor v1; shown as a server-rendered table on `https://gd.eppo.int/taxon/{code}/pathwayshosts`. Coverage in master_species.xlsx: 222 of 279 A1/A2 pests (80 %), 0 of 39 Alert-list pests. AGRLAX: plants for planting, squared wood, non-squared wood, bark, manufactured articles, packaging material, all Betula.
